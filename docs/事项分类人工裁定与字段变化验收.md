## 2. 实现及采用口径

### 2.1 统一字段事实

新增 `backend/src/dake/domain/fields.py` 和 `backend/src/dake/analysis/field_changes.py`。事件 JSON 增加 `version`、`field_states`、`field_issues`、`manual_operations`，沿用现有存储与事务，不新增业务表。

字段目标由公共字段、标签、六类专属属性字典限定。事实分别保存值及值状态、环节、对象/范围、业务时间原话、计划/实际性质、变化意图、被替换事实编号、理由和该字段的直接引文。引文保存消息来源、ID、digest、发送时间与群；业务时间未知时保持 `null/unknown`，不以发送时间或人工操作时间代替。

正式 `AttributionOutput` 升为 schema 5.0，要求 `field_updates`。正式 XHub 入口拒绝 schema 4.0 并进入已有的一次修复流程；兼容投影不能同时直接写入状态、等级、跟进人或类型属性。基础提示词文件和既有分析流身份未改，当前规则附加于正式归属策略，避免因合约升级自动重洗旧数据。

同一事实槽位按环节、范围、业务时间及时间性质定位：独立阶段进展保留旧事实；同一槽位不同值保存为待复核建议；明确更正须精确引用本字段事实，并保持更正对象的环节和范围。`batch:ref` 仅在当前候选内解析，不能引用上一轮的同名引用。更正历史事实不能顺带覆盖另一条当前事实。

字段值须出现在其直接连续引文中，时间须来自直接引文原话。程序校验引用、版本和结构约束；原文是否真正表示该字段或更正仍依赖 Provider 的语义判断。不同单位、相对日期和范围表述不作自动等价归一。

属性的多个采用事实分别保存，兼容字符串投影以 `；` 连接不同值。公共标量字段仍投影单个当前值；锁定公共字段不能通过另取环节名称绕过保护。锁定属性允许独立阶段事实继续记录，不能据此把原锁定事实改值。旧记录按需迁移，未记录的环节、范围和依据保持未记录，不补造。

状态和等级的配置缺省仅作未提供时的投影：没有明确抽取记录且值等于当前配置缺省时，不迁移为已证实旧事实。真实历史非缺省值，以及当前或连续同值旧修订里明确记录的字段事实，仍作为已有事实保护；已有字段状态中的人工未知和主动清空不走缺失值分支。此次未执行批量历史改写，也不把完全没有来源记录的缺省字符串认作有证据事实。

### 2.2 人工写入与并发

新增 `backend/src/dake/services/field_decisions.py`，自动处理与人工提交共用客户锁及数据库事务。新增接口：

- `POST /api/v1/events/{event_id}/field-decisions`：显式提供客户、分析范围、旧版本、操作编号、操作人、理由和动作。
- `GET /api/v1/events/{event_id}/field-decisions/{operation_id}`：只读查询已提交操作收据。

支持确认、填写裁定值、主动清空、未知、不适用、锁定、解锁、采用指定建议、保留当前值并解决指定问题。主动清空、未知、不适用与未提供字段分开记录；请求未包含的字段不清空。

旧版本提交返回 409；同一操作编号及相同请求重试不追加修订，同编号不同请求返回 409。动作组任一无效则整组回滚，操作收据与事件同事务保存。人工事实记录操作编号、操作人、理由及裁定时间；引用旧聊天时仅作为参考，不能声称人工新值是聊天原话。

解锁只解除保护，不改采用值、不消除疑点。采用和解决动作必须明确指定问题编号，其他字段或未选问题继续保留。确认、锁定和解锁不能附带消除问题。撤销标签若影响属性或锁定决定，须明确归档这些依赖；已撤销标签的属性不能绕过标签恢复直接裁定。

人工修订以 `source=manual` 和 `recorded_at` 独立保存，消息触发列表为空。既有修订结构中的窗口字段仅保留兼容锚点；自动周期快照及原自动收据恢复明确排除人工锚点，不把后来裁定回填为当时自动结果。

自动和人工写入均在最终字段投影后维护 `closed_at`。它沿用关闭宽限检索的消息观察锚点：首次进入配置的关闭状态取事项已有 `end_time`，已关闭时仅补依据不延长原锚点；最终采用状态重开、清空、未知或不适用时清除锚点。锁定状态不受未采用建议影响。该字段不是业务实际完成日期，人工裁定的操作时间不写入其中，业务时间没有直接依据时仍为空。

### 2.3 页面与合约

新增 `web/src/components/FieldDecisions.tsx`，当前事件页提供人工入口，详情展示采用事实、建议、历史、锁定、环节、时间、问题和版本依据。变化面板显示人工操作人、理由及人工时间；历史详情展示当时快照，入口只读。

编辑器保留打开时的版本基线，轮询更新不覆盖草稿；409 后保留草稿，由用户主动核对当前版本。网络中断或 503 被标为提交结果待核对，关闭再打开对话框保留该操作编号，先查询收据和当前事件，不自动重复写入。这一状态保留在当前页面组件内，未实现跨整页刷新持久化。找不到收据时保持待核对，未增加自动重试写入入口。

OpenAPI 经 `scripts/export_openapi.py` 导出，再由 `npm run openapi` 生成客户端；未手工修改生成文件。配置接口提供可裁定字段字典，页面通过服务层及生成客户端提交。
